# gomimap（ごみまっぷ・仮称）

日本の家庭向けに、収集予定と分別方法を案内するFlutterアプリです。iOS／Androidを対象に、まず東京都豊島区で検証し、自治体ごとのルールを扱える構造で全国へ拡張する計画です。自治体の公式アプリではありません。

## 開発状況

現在は開発用プロトタイプです。**収集日・地域・回収拠点は架空のサンプルで、実際のごみ出しには使えません。** ストア公開版はまだありません。

| 状態 | 内容 |
| --- | --- |
| 実装済み | 今日・明日・今後の予定表示、サンプル地域の保存、分別検索、特殊品目の回収場所画面、10種類の言語選択と保存 |
| 地図描画を実装 | `flutter_map`へ移行済み。タイル配信元は未設定で、標準起動時は未接続表示 |
| 開発中・計画中 | 豊島区の公式データ、位置・住所による地域設定、通知、両OSのウィジェット、粗大ごみ条件確認、データ更新・監視 |
| 未検証 | iOS／Androidのネイティブビルドと実機動作、各言語話者による翻訳確認、利用者検証 |

通常の家庭ごみ・資源は予定と分別案内で扱います。地図の対象は電池・小型家電・蛍光灯など、専用の回収先を探す品目です。写真AIは将来の検討対象です。

## 開発を始める

Flutter **3.47.6**／Dart **3.13.5**を使用します。Flutterを準備してリポジトリ直下から実行してください。

```sh
cd app
flutter pub get --enforce-lockfile
flutter run -d chrome
```

Webは画面確認用です。Flutterの導入方法、プロジェクト内SDKを使うコマンド、ネイティブ環境、地図のローカル設定は[開発手順](docs/development.md)を参照してください。ローカル開発とテストにAPIキーやストア登録は不要です。
