# 日本全自治体の調査試験台帳

[Issue #75](https://github.com/oukiito/gomimap/issues/75)。利用者指定：**日本の全自治体を対象に、GPT-6 Luna・reasoning effort highで調査試験する**。豊島区と人口上位3市だけの調査へ限定しない。

母集団は[人口候補一覧](../README.md)の全1,747行。人口が正の1,741行を全国の調査対象に含め、原表で人口0の6行は`scope_review`として別確認する。0を削除したり、実在・行政の扱いを人口だけで断定したりしない。政令市の行政区は親市内の調査対象とし、市とは別の全国候補として重複計上しない。

## 担当と進め方

| ファイル | 対象の総人口順位 | 指定モデル | effort |
| --- | --- | --- | --- |
| [shard-1.json](shard-1.json) | 1, 4, 7… | gpt-6-luna | high |
| [shard-2.json](shard-2.json) | 2, 5, 8… | gpt-6-luna | high |
| [shard-3.json](shard-3.json) | 3, 6, 9… | gpt-6-luna | high |

3担当が各順位を昇順に進める。分割は担当の競合を防ぐためで、他の自治体を対象外とする理由ではない。調査の実行環境で指定したモデルとeffortを、実際に調べた行にのみ記録する。未着手行へ実行済みの日時・モデルを付けない。

最初に全自治体の公式資料と区域の決まり方を確認する。その後、自治体内の全区域・注記・例外・適用期間・利用条件・期待値をMR01〜09で詳細に突き合わせる。公式入口を見つけた割合と、自治体内の全区域調査が完了した割合を別々に報告する。

## 状態の意味

| status | 意味 |
| --- | --- |
| unresearched | まだ公式資料を確認していない。調査済みではない |
| source_identified | 公式資料を特定したが本文読取・区域条件の確認は未完了。検索結果だけの場合を含む |
| partial | 公式本文の一部を読み、区域条件等を確認した。全区域の網羅やMR完了を意味しない |
| blocked | 取得不能等の具体的な障害がある。理由・参照先を記録する |
| scope_review | 統計上の0人口行等について提供対象・行政の扱いの確認が必要 |
| research_complete | 全区域の根拠、MR01〜09と独立した期待値、重大な未解決の解消が揃った別判定。アプリ実装・公開の許可ではない |

sourcesの`access`はread（本文読取）／search_only（検索結果のみ）／failed（取得失敗）。`locator`は原文内の確認箇所。findingsは短い要約で出典との対応を残す。原PDFや日程表全文は収録しない。`checked_on`は閲覧日で、制度の適用日ではない。

公式URLを確認できなかった検索は、URLを推測して登録しない。実際の検索語を`attempts`（method=`web_search`, query, outcome=`official_source_not_verified`）へ残し、sourcesが空のblockedとして再調査へ回す。調査を実行した日時・モデルを保持し、未着手と区別する。この場合のblockedは永久に調査不能という判定ではない。

`coverage`のknown_subareasは母数、examined_subareasは実読した区域数。件数を使う場合はunitとcount_basisで数える単位・根拠を付ける。行政区の数、収集区域の数、閲覧したページ数を混ぜない。母数未集計はnull、閲覧件数を区域数へ変換できない場合はexamined_subareas=0とし、実際に読んだ範囲をsources/findingsへ記録する。whole_municipality=trueには母数一致だけでなくscope_evidenceを必須にする。

## 検査と限界

```sh
python3 scripts/validate_nationwide_survey.py
python3 -m unittest discover -s scripts/tests -v
```

検査は全国候補の抜け・重複・人口順位の変更、モデル指定、根拠と進捗の取り違え、母数なしの全域完了宣言を防ぐ。**資料の内容が正しいこと、LLMが誤読していないこと、利用許可、実住宅照合の正確性は自動検査だけでは証明できない。** 原文照合・人の確認・アプリと実機の試験は別に残す。

研究用の台帳でありアプリへ配信しない。市町村の統計と公式公開資料へのリンク・自作要約のみを扱い、個人宅住所・位置履歴・認証情報を入れない。日程の本番採用・全文転載・外部問い合わせは、この試験で自動的に許可されたものではない。

継続時は未調査の最上位から再開する。partialも完了件数に数えず、全区域の後続調査へ残す。途中成果のPRで全国調査Issue #75を自動closeしない。
