# 残る実装の受け入れ試験

2026-10-09。#3・#5〜#12。[残る設計](remaining-design.md)の実装PRで、以下のID・条件・結果・証拠を記録する。未実施の項目を計画書だけで合格にしない。ストア申請はこの試験の着手条件ではない。

実装前に具体的な期待値と証拠を固定する追加契約は[開始ゲート G1〜G7](implementation-readiness.md#試験と開始ゲート)を参照。fixture・論理試験・OS実配送・実機の成功を区別する。

## 環境と証拠

論理試験、OSネイティブ試験、実画面、実機、利用者観察を分ける。時刻・位置・権限変更・初期状態の再現は隔離した試験ターゲット／AVD／Simulatorで行う。個人Pixel／iPhoneのOS時計・全体の文字設定・ネットワーク・アプリデータを勝手に変更しない。実機は対象アプリに必要な操作と状態保持を確認する。

共通の試験時計はDartとネイティブの両方へ同じUTC instantを渡す。専用ビルドだけに許可し、製品ビルドで無効なことを検査する。ウィジェットはDartだけのclock注入で再現済みとしない。現在時刻を使うSmokeと、境界を進める試験を分ける。

証拠にはソースcommit、APK／アプリの版、データkind・版・区域、OS、文字サイズ、言語、注入時刻、操作、期待値、assert結果、重要箇所のPNGを対応付ける。PNGは対象アプリ／ウィジェットへ絞り、ログ・端末ID・位置・通知の私物情報を公開しない。Flow・fixtureはGit、確認前の生ログはGit対象外、点検済みの結果はdocs/workへ。

## 現在と合格条件

2026-10-09に[Android QA時計](qa-clock.md)を実装し、締切直前・ちょうど・日本0時・複数締切・今日不明・次回・データ期限の9ケースを専用エミュレータで確認した。V01／V02のAndroid固定時刻での判定・実描画を部分完了とする。OSアラームの実到達、iOS、実データ、その他のV項目は完了扱いにしない。[記録](work/2026-10-09-android-clock-qa.md)。

共通判定の一部、Android SDKの49項目、専用エミュレータの日英A01〜A04は[既存の記録](work/2026-10-09-maestro-ui-poc.md)にある。ただしV01〜12全体は未完了。特に時計を進めた実画面、通知、実GPS区域、iOS、実データ、運用、人の利用者検証は、この設計時点で合格としていない。

自動UI用CIは、局所のFlowが安定してから専用エミュレータの失敗・PNGを保存するジョブを設計・導入する。現在の必須CI `app`をUI／実機合格と読み替えない。外部PRへ秘密を渡さない。CIの署名、試験時計、テスト通知、fixtureの識別は製品ビルドと分ける。

公開ゲートは[roadmap](roadmap.md#一般公開ゲート)へ集約する。機能の合格、原文・利用条件の合格、人の使いやすさの合格を別々に記録し、人が一般公開を判断する。協力者や許諾が揃わなければ試用版として継続し、未実施を省略して完了にしない。
