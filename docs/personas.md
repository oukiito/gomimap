# 利用者ペルソナ

状態：2026-10-06作成。利用者の希望に基づく設計仮説。インタビュー・観察による検証は未実施。関連：[Issue #16](https://github.com/oukiito/gomimap/issues/16)。

## 対象の捉え方

対象は、家庭のごみ出しを担う人と、日本の分別ルールに慣れていない人。主婦・主夫や外国人住民を含むが、性別・国籍・職業からスマホ習熟度や日本語力を決めない。下記の人物像は架空で、実在の利用者の調査結果ではない。同じ人が両方の状況に当てはまることもある。

初期地域は豊島区。集合住宅独自の回収日、事業ごみ、全国の未検証データは対象外。製品の提供範囲は[プロダクト仕様](product-spec.md)に従う。

## P1：朝の準備中に、今日出すものだけ確認したい人

代表例：家庭のごみ出しを担当する主婦・主夫。朝は家事、育児、外出の準備などが重なり、片手で短時間スマホを見る。日本語は読めるが、分別用語や設定画面に詳しいとは限らない。

| 項目 | 想定 |
| --- | --- |
| したいこと | 袋を持つ前に、今日出す区分と締切を確かめたい。収集がなければ次回を知りたい |
| 困りごと | 月2回の収集を覚えにくい。カレンダーを探す手間がある。通知だけでは見逃すことがある |
| 使う場面 | 起床後・台所・玄関。ウィジェットを一目見るか、アプリを起動する |
| ときどきすること | 電池や家電を処分するとき、出し方と行ける回収先を調べる |
| 避けたい負担 | 毎朝の検索・地域選択、会員登録、宣伝、設定の強制、細かい文字 |
| 成功条件 | 設定後、日々の確認操作なしで今日の全区分・締切が分かる。収集なしと不明を取り違えない |

設計への反映：通常起動は「今日」。今日を最優先にし、明日と次回を続ける。ウィジェットは追加を必須にせず、アプリと同じ日程・確定状態を示す。通知は任意で、時刻変更可能にする。

## P2：日本の分別ルールを調べながら、ごみを出したい人

代表例：豊島区へ転入した外国人住民。スマホには慣れているが、日本語の行政用語や日本の分別ルールに不慣れ。読める言語、日本語力、在住期間には個人差がある。日本人の転入者にも共通する場面を含む。

| 項目 | 想定 |
| --- | --- |
| したいこと | いつ出すかに加え、この品物を何に分け、どう準備し、どこへ出すか知りたい |
| 困りごと | 「資源」などの区分名だけでは中身が分からない。前の居住地のルールと違う。公式ページを読みにくい |
| 使う場面 | 引越し後の設定、片付け中、捨てたい品物を手にしたとき |
| 必要な手がかり | 読める言語、普段使う品名、具体例、品物の図と文字、短い準備手順 |
| 避けたい負担 | 日本語が分からないと言語設定へ到達できないこと、専門語だけの結果、根拠不明の翻訳 |
| 成功条件 | 自分の言語で品物を探し、区分・準備・次の行動を説明できる。特別な品目は条件に合う拠点を選べる |

設計への反映：言語切り替えは初期設定から使える。言語名はその言語自身の表記で示し、国旗で言語を表さない。分別結果では区分名だけで終わらず、必要な準備と出し先を示す。施設・地域名は現地の看板や住所と照合できる原表記も残す。

既存の10言語のUI表示は、全品目の多言語検索・公式データの翻訳・各言語話者による確認の完了を意味しない。検索の別名と自治体ルールの翻訳を別途検証する。写真AIを使えなくても、基本の検索と条件確認を完了できるようにする。

## 共通する利用場面

| 場面 | 利用者が答えを得たいこと | 最短の導線 | 設計ID |
| --- | --- | --- | --- |
| 朝のごみ出し | 今日出せるものと締切 | ウィジェット、または通常起動後の「今日」 | UX01・UX02 |
| 捨て方が分からない | 区分、準備、いつ・どこへ出すか | 分別検索 → 品物の出し方 | UX03 |
| 電池などを持ち込む | この品物を受け付ける、行ける場所 | 品目と必要条件 → 地図 → 拠点 | UX04 |
| 引越し・初回利用 | 自宅に合う収集予定を設定できるか | 現在地候補／住所 → 地域確認 | UX05 |
| 情報が不確か | 今は何を確認すべきか | 確認が必要な項目 → 対象の公式情報 | UX06 |

設計IDの詳細と試験は[UI・画面遷移の設計](ux-design.md)に記載する。

## 利用者検証で確かめること

5人程度の最初の試験には、家庭のごみ出し担当者、日本語の行政用語に不慣れな人、スマホ操作に不慣れな人を含める。属性は重複してよい。外国人住民を一つの言語・習熟度で代表させず、使用言語・日本語力・分別経験を記録する。少人数の結果を全利用者の傾向と断定しない。

個人の住所・国籍を公開記録に収集する必要はない。架空の地域と品物で試験できる。確認した言語の結果を未確認の他言語へ広げない。

観察では「使いやすいですか」だけでなく、今日出すものの読み取り、分別方法の説明、条件に合う回収先の選択を試す。時間、誤り、手助け、戻り操作の迷いを記録し、[試験手順](ux-design.md#利用者試験)で再確認する。
