## 設計へ反映した発見

[瑕疵点検 MA01〜10、NC06〜09、A01〜12](matching-audit.md)に、根拠・影響・対策・未検証を保存した。特に住所とは別の集積所所属、建物と収集主体、品目限定例外、収集目安と排出期限の区別が必要。GPS一回で全方式を確定する設計は採らない。

## 次の作業と完了の意味

1. 豊島区の先行調査と、人口上位3市の全対象行・注記の棚卸しを進める。利用条件未確認の原文を公開fixtureへ転載しない。
2. 順位4〜10を同じMR票へ展開する。[町村・島しょ・広域処理の一次調査](representative-regions.md)から詳細票を作り、人口順の導入順位を変更しない。
3. 対象範囲の独立した正解・境界・反例、資料間差分、所属を利用者が確認できる方法を揃える。
4. MRの重大未解決を解消した範囲からv2 codec・保存・UI投影の設計レビュー後に実装する。研究用人口スクリプトの成功は住宅照合の実装ゲートの合格ではない。

「入口確認」は公式資料の所在・構造の一部を確認しただけ。「詳細着手」も全域のMR完了ではない。現時点でMR01〜09完了と判定した自治体は0。利用者の追加回答待ちで調査全体を止める必要はない。原文の利用許可・人の確認が必要な事項は、その対象資料のゲートとして別管理する。
