# 地図ライブラリの移行

日付：2026-10-06。GitHub CLI未認証のため、Issue・PR登録前の作業記録。
公開予定先は`oukiito/gomimap`。この記録は開発計画のG03・G09に関連し、G04（スキーマと日程ルール）とは別。認証後に以下をIssue／PRへ転記する。

## Issue案：Google Maps依存を外し、資源回収場所をflutter_mapへ移行する

GPL方針に合わせてGoogle製SDKの依存を除去する。電池・小型家電等の地図に限り、日常のごみは今日の画面で確認する既存仕様を維持する。

受け入れ条件：
- Google Maps関連のDart依存・初期化・APIキー設定が残っていない。
- 設定が揃った場合はWeb／モバイル共通のFlutter地図を描画できる。
- 帰属表示がない配信設定では有効化しない。
- ピンを選ぶと対象拠点の既存詳細へつながる。
- サンプルを実在の拠点として案内しない。公開配信サービスを暗黙に選ばない。

## 実装

`flutter_map 8.3.2`と`latlong2 0.9.1`を導入。3つのdart-defineでHTTPS XYZタイルと帰属表示を設定する。設定なしでは従来の未接続表示。Google Mapsの依存とiOS／Androidのキー設定を除去。

依存ライセンス一覧を86パッケージへ更新。現行一覧から削除済み依存の通知を消すよう生成スクリプトを調整した。ネイティブ成果物全体の監査は未完了。
