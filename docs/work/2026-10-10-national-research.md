# 全国候補人口集計と住宅照合の追加調査

2026-10-10。[Issue #73](https://github.com/oukiito/gomimap/issues/73)、[PR #74](https://github.com/oukiito/gomimap/pull/74)、親[#53](https://github.com/oukiito/gomimap/issues/53)。基準 `fba6e43`、ブランチ `codex/73-national-municipality-research`。

## 実施内容

- 利用者が総人口優先を確定。方針・D38・AGENTSを更新した。
- e-Statの2026年表26-03／26-11を取得してコードで結合。市町村・東京特別区の原表1,747行を順位化、人口0の6行を明示して保持。171行政区と355集計行を除外した。原本は非公開のローカル作業用、公開するのは人口集計CSV・除外行・出典と検算。
- 横浜・大阪・名古屋を自治体別台帳にし、豊島区の現行リンクと調査限界を追記。順位4〜10と、町村・島しょ・広域処理に関する反例候補を一次確認した。
- 所属・建物・品目例外・収集目安と排出期限等をMA01〜10へ記録。NC06〜09のUI理由とA01〜12の設計期待値を追加。アプリの住宅照合を先行実装していない。

## 検証と限界

| 確認 | 結果 |
| --- | --- |
| 原表人口の整合 | 総人口123,767,642人、外国人住民4,031,159人で国の計と一致。47都道府県・20政令市の区計も両指標で一致 |
| 別読取経路 | openpyxlと標準ライブラリXML読取を比較。各表A/B/C/Fの非空9,107セルが一致。openpyxlは既存の分析環境で使用し、プロジェクト依存に追加していない |
| 人口スクリプト | 読み仮名がセル本文に混入した初回失敗を修正。hash・見出し・時点・人口の計・欠測・コード結合・除外・順位・集計を検査 |
| Python回帰 | 81テスト成功（新規8件）。欠測と0、ふりがな、重複・結合誤り、行政区二重計上、未知の地理行、同数順位、公開集計の整合を含む |
| 出典登録簿 | 14件valid、再配布未承認12件のまま。新しい日程データの承認・公開はしていない |
| 文書の読者確認 | doc-coauthoringによる会話履歴なしのAI読者が、完了範囲、順位、所属不明、時間表示、実装ゲート、次の調査を確認。重大指摘なし。人の原文承認ではない |
| 文書・公開範囲 | 変更文書のローカルリンク228件の参照先が存在。原統計・日程表全文・個人宅・秘密情報を新規公開ファイルに含めていない |
| Flutter・実機 | ローカルで新規実行なし。アプリコード・端末・通知・デプロイを変更していない |
