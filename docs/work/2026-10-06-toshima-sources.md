# 豊島区の出典登録簿と利用条件の検査

日付：2026-10-06。関連：[G02／Issue #2](https://github.com/oukiito/gomimap/issues/2)。

## 実施したこと

- READMEの「開発を始める」を「技術構成」に変更し、セットアップの命令文と重複するコマンドを開発手順へ集約した。
- 公式のHTML・PDF・CSV計14件と利用条件2件を確認し、[機械可読の登録簿](../../data/sources/toshima.json)を作成した。収集曜日・区域例外・特別日・分別・拠点・受付条件をカバーする。
- 現在の資源案内がリンクする1ページの収集曜日PDFを一時取得して画像で確認。一般区域・繁華街区域の表、番地条件、締切、月内曜日の説明を確認した。以前の4ページ資料を同じ版として扱わない。
- 公共施設CSVの緯度・経度・住所・時間関連の列を確認した。施設一覧をそのまま回収拠点一覧として使わない。
- 原資料を配布物へ収録せず、取得日時の種類と内容ハッシュだけをメタデータへ保存した。一時PDF・画像は確認後に削除した。HTML本文、画像、施設データ行はGitへ追加していない。
- 一般サイト方針と対象限定のCC BY 2.1 JPを区別し、継続保管と再配布の状態を別々に記録した。14件中、再配布条件を確認できたものはCSV2件。残る12件は要確認。
- 再配布条件の未確認、ライセンス対象外のURL、出典表示なし、過年度資料、未登録・空の参照、重複ID等を拒否する検査を実装した。
- Python標準ライブラリによる回帰テスト12件が成功。登録簿と検査を既存の必須CI appへ追加した。

## 確認主体と限界

調査・検査はCodexによる確認であり、自治体の許諾回答、独立した人の原文照合、実機確認ではない。登録簿の確認済みという状態はアプリ用データの公開承認を意味しない。

一般Web資料の継続保管、機械取得、構造化・翻訳、アプリへの同梱・配信、LLMへの送信の条件は未確認。[問い合わせ文案](../sources/toshima-reuse-inquiry.md)を作成したが送信していない。回答が必要な部分は[Issue #14](https://github.com/oukiito/gomimap/issues/14)へ分けて追跡する。アプリは引き続き架空のサンプルで動作する。

日程・受付条件・座標の実データ化はG04／G09、取得・公開経路への検査の接続はG10で行う。G02の調査完了を、自治体データの配布準備完了と扱わない。
