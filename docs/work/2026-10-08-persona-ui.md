# AI模擬操作で確認したUIの改善

日付：2026-10-08。関連：[Issue #23](https://github.com/oukiito/gomimap/issues/23)、G05・G09・G12。

## 実装と確認

同じ開発AIが3つの利用場面を想定してWeb試作を操作した。実装を知っている評価で、独立したAI評価・人の利用者観察とは区別する。[実操作・修正前後の画面](../ux-evaluations/2026-10-08/report.md)に条件・操作・観察の事実・影響の仮説を記録した。

締切をカードへ表示し、詳細へ見える閉じる操作、検索から開いた回収場所へ元の品物へ戻る操作を追加した。直接回収場所を開く場合は品目未選択とし、充電池の状態未判定を0件と表示しない。操作・状態保持・失敗時の理由は[設計N01〜10](../ux-disposal-navigation.md)へ記録した。全言語の文言を更新・生成した。

Flutter全121テスト、解析、整形、Webビルドを確認した。文字200%と十言語で新しい操作へ到達できること、OS戻る・元の回答復元・タブ再訪の保持を回帰テストで確認した。ブラウザは390×844で実操作し、模擬データの画面だけを撮影した。人の操作感・理解、翻訳話者、ネイティブビルド・実機は未検証。GitHub CIの結果はPRへ記録する。

会話履歴を渡さない文書読者役のAIが、評価主体・架空データ・実操作と自動検証・戻り・未実装の範囲を読み取れるか確認した。判定済みの0件と未判定の違いを設計へ追記した。これは文書の読解確認で、UIの独立評価・人の試験・コード承認ではない。

## 残る作業

実地区GPS、受入判定・実拠点・地図タイルの画面接続、データHTTP更新・端末保存、通知・ウィジェットは後続。実地・人の検証をAI実操作の成功で代用しない。Cloudflareは未接続で、アカウント保有・ドメイン未取得を確認したのみ。認証・配信基盤の準備はこのUI変更と別の作業として管理する。
