# 利用者ペルソナとUI設計の整備

日付：2026-10-06（Asia/Tokyo）。関連：[Issue #16](https://github.com/oukiito/gomimap/issues/16)。

## 変更

利用者の「全UI・UX・画面遷移に理由を付ける」「使いやすさを優先し、設計中も助言・指摘する」という指定を、設計書と開発運用へ反映した。

- [ペルソナ](../personas.md)：忙しい朝のごみ出し担当者、日本の分別に不慣れな住民。主婦・主夫や外国人住民を含め、属性とスマホ習熟度を混同しない。
- [UI設計](../ux-design.md)：8つの判断基準、14の画面・表示、26の遷移・主要操作。各用件の理由、状態保持、戻り方、拒否・通信失敗・不明時の動作を記録。
- 利用者試験の7つの用件と観察項目を設計し、現在の試作との差を既存Issueへ対応付けた。
- CONTRIBUTING、機能Issue・PRテンプレートへ理由・検証・未実施事項の記録を追加。
- プロダクト仕様、決定記録、文書一覧、ロードマップ、CHANGELOGから参照可能にした。

地図は電池など特別な品目の持込先向けとする既存方針を維持した。通常の資源・家庭ごみの集積所を公共の持込先として掲載する設計には変更していない。

## 確認

- リポジトリ内Markdownのローカルリンクの参照先を確認し、個人PCの絶対パスを含まないことを確認。
- 設計IDの重複を確認。14の画面、26の遷移、7つの試験用件を記録。
- `git diff --check`で空白・差分の異常なし。
- 会話履歴を渡さないAIによる読み手確認で、利用者・起動先・地図対象・状態保持・実装状況・変更時の理由を確認。地図で品目を変えた後の戻り先の回答復元と、未確認／休止でピンがなくなった際の表示の曖昧さを修正した。実利用者による観察や独立した人のレビューとは数えない。
- 文書だけの変更のため、ローカルでアプリのテストを追加・再実行していない。PRの必須CIは別途実行する。

## 未実施

ペルソナはインタビュー前の仮説。利用者試験・各言語話者による確認・両OSの実機試験は実施していない。この変更は画面の実装、自治体の実データ公開、通知・ウィジェットの提供を含まない。

本実装ではG05〜G09のIssueに設計IDと確認結果を記録し、G12で利用者の観察と修正後の再確認を行う。データ・ネイティブPoCの依存は[開発計画](../roadmap.md)を参照。
