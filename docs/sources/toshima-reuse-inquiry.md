# 豊島区への利用条件の問い合わせ文案

状態：未送信。窓口は[ごみ減量推進課](https://www.city.toshima.lg.jp/150/kurashi/gomi/shigen/009426.html)、サイトの権利方針は[広報課](https://www.city.toshima.lg.jp/012/kuse/koho/homepage/sitepolicy.html)に確認する想定です。担当窓口・連絡方法は送信時に公式ページで確認します。送信者名・連絡先をこの公開文書へ記載しません。

## 件名

家庭ごみの収集・分別・拠点回収情報のデータ化とアプリ提供に関する利用条件の確認

## 本文案

豊島区の家庭ごみの収集予定、分別方法、乾電池・小型家電・蛍光灯等の回収場所を案内する非公式アプリ「gomimap」を開発しています。対象はiOSとAndroidです。初期版は無料・広告なしで、アプリの自作ソースはGPL-3.0-or-laterで公開しています。区の資料をこのライセンスへ変更する意図はありません。

対象資料は[出典一覧](toshima.md)の収集曜日PDF、分別案内、年末年始・荒天時のお知らせ、回収拠点・受付条件です。区の一般サイト方針と、オープンデータのCC BY 2.1 JPが指定データだけに適用されることを確認しました。以下の利用について、適用条件または利用可能な別の公開データをご教示いただけますでしょうか。

1. HTML・PDFを更新検知と照合のために取得し、非公開で一定期間保存すること。
2. 収集曜日・区域の条件・締切、施設住所・回収品目・受付条件を構造化し、アプリに同梱、またはHTTPSで配信すること。原文の画像・イラスト・PDF本体は配布しない想定です。
3. 案内の短い文章を独自に作成し、複数言語へ翻訳すること。公式URLと確認日を表示し、独自加工した情報であることを明示する想定です。
4. 定期取得の可否、推奨する取得頻度・方法、公開CSV／APIの有無。通常情報は週1回、お知らせは1日1回を検討しています。
5. LLMを更新候補の抽出に用いる場合の、外部サービスへの資料送信・一時保管に関する条件。資料をモデルの学習へ提供しない構成を検討しています。
6. 必要な出典表示、対象範囲、利用期間、再配布・改変の制限、将来の運用形態変更時に再確認する条件。

収集日・分別・受入条件の変更は原文と照合して公開し、未確認の予定は断定しません。区の公式アプリや、区が監修・承認したアプリであるとの表示は行いません。

## 回答後の記録

回答日、対象URL、認められた操作、出典表示、制限、有効期間、担当確認を登録簿に反映します。回答全文や担当者の氏名・連絡先を無断でGitHubへ公開しません。送信・回答を得たことにしないまま、利用条件を許諾済みへ変更しません。
